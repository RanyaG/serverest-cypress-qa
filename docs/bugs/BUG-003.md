# BUG-003: Botão "Adicionar no carrinho" tem dois `data-testid` e um deles se perde

| Campo | Valor |
|---|---|
| Severidade | Baixa (não afeta o usuário; afeta a testabilidade) |
| Prioridade | Baixa |
| Status | Aberto |
| Módulo | Loja (cliente) › Lista de Compras |
| Ambiente | front.serverest.dev, Chrome. Reproduzido também numa cópia local do front |

## Passos para reproduzir

1. Entrar como cliente e adicionar um produto à lista.
2. Na Lista de Compras, inspecionar o botão **Adicionar no carrinho**.
3. Procurar o seletor `[data-testid="checkout-products"]`.

## Resultado esperado

O botão pode ser encontrado por `data-testid="checkout-products"`, como está no código.

## Resultado obtido

Nenhum elemento é encontrado. O botão só tem `data-testid="adicionar carrinho"` (com espaço).

## Causa provável

Em `src/views/client/ListCart.js`, o `<button>` declara `data-testid` duas vezes. No JSX, o último valor vence, e o primeiro é descartado sem aviso.

## Sugestão de correção

Manter um único `data-testid`, sem espaço. Se suítes públicas já usam o valor atual, manter `adicionar carrinho` e remover o outro.
